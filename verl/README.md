# veRL — Distributed RL Infrastructure

Vendored copy of [veRL](https://github.com/volcengine/verl) (Volcano Engine Reinforcement Learning for LLMs), with modifications for UFO multi-turn training.

**Install**:
```bash
cd verl
pip install -e . --no-dependencies
```

**Note**: This is automatically installed by `scripts/setup_ufb.sh`.

For veRL documentation, see [github.com/volcengine/verl](https://github.com/volcengine/verl).
