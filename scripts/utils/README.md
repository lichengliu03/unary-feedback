# Utility Scripts

| Script | Purpose |
|---|---|
| `convert_fsdp_to_hf.py` | Convert FSDP checkpoints to HuggingFace format |
| `convert_out_to_json.py` | Convert raw evaluation output to JSON |
| `compute_conditional_success.py` | Compute conditional success rates from results |
| `analyze_parser_failures.py` | Analyze answer parsing failures |
| `test_critique_env.py` | Test critique feedback environment |
| `test_passk_logic.py` | Test Pass@k metric computation |
| `config_critique_example.py` | Example critique configuration |
| `check_experiments.sh` | Monitor running SLURM experiments |
